# Security Audit — 0xsigner — 2026-10-21 (re-run)

## Summary

Re-run of the 2026-10-20 audit. Browser-based Cloudflare signer-worker generator (Vite/React, MKStack-derived). **No code changes since the previous audit** (HEAD still 9e48a1c, 2026-09-22). The HIGH finding was re-verified directly in `src/lib/signer/runtime/core.ts` today: `checkPublicAuth()` still returns `true` unconditionally for `publicAuth: { type: 'nip98' }` (comment: "presence-only here"), and no per-route NIP-98 verification exists — selecting NIP-98 auth in the wizard yields a **completely unauthenticated gateway** while the UI implies enforcement. CORS allowlist-reflection, SSRF guards, body caps, and the manifest/secret separation contract remain correctly implemented.
